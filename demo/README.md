# 演示视频材料

本目录用于保存比赛要求的最终演示视频和相关脚本，对应官网要求：

> 演示视频：5–8 分钟（MP4，1080p）。除功能演示外，必须包含至少 2 分钟的“AI 协同过程复现展示”。

## 目录内容

```text
demo/
├─ README.md
├─ script.md              5—8 分钟逐段讲稿和画面清单
├─ video-timeline.md      AI 协同 ≥ 2 分钟的时间轴对应关系
├─ screenshots/           视频关键帧或演示关键截图
└─ 议场AGORA-最终演示视频.mp4   （本地录制后放入，默认不入 Git）
```

## 视频硬性要求

| 要求 | 标准 | 当前状态 |
|---|---|---|
| 时长 | 5–8 分钟 | 待录制 |
| 分辨率 | 1080p | 待录制 |
| 格式 | MP4 | 待录制 |
| AI 协同过程 | 至少 2 分钟 | 待录制 |
| 功能演示 | 覆盖议题、Agent、质询、冲突、决议、回放 | 待录制 |
| 音频 | 讲解清晰 | 待录制 |
| 文字可读 | 浏览器和 Cursor 字号可辨认 | 待录制 |

## 大文件约定

MP4 文件通常超过 Git 建议体积，不建议直接提交到仓库。建议：

1. 视频文件保存于本地或网盘；
2. 仓库中保留录制脚本、时间轴和关键帧截图；
3. 若官网只接受上传，则直接上传 MP4；
4. 若允许外链，请在 `deliverables/README.md` 中登记链接和访问方式。

不得用截图拼接冒充视频，也不得剪辑掉关键 Prompt 输入和 AI 修改过程再声称“完整复现”。
