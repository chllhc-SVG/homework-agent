# 技术文档附录

本目录用于存放 PDF 技术文档（`deliverables/technical-document.md`）的附录材料。附录不替代正文中的必需章节。

## 建议内容

| 编号 | 附录 | 说明 |
|---|---|---|
| A | `A-commit-prompt-video-map.md` | Git 提交—Prompt 轮次—视频时间点对照表 |
| B | `B-reproduction-log.md` | 复现命令与结果记录（typecheck/test/build/contest:verify） |
| C | `C-scenario-comparison.md` | 校园节能/课程反馈/校园就业三场景差异对比表 |
| D | `D-evidence-index.md` | 截图、录屏、原始导出的文件清单与 SHA-256 |

## 页数控制

技术文档正文不超过 30 页；附录如需扩张，请优先保留对照表，删减重复文字说明。附录截图必须来自真实运行，不得使用设计稿。
