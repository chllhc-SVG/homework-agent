### 2. 解题有效性与实用价值（25%）

对应产品设计：

- 面向真实的校园团队决策场景；
- 不是普通聊天窗口，而是有角色职责、证据和异议记录的决策流程；
- 输出可执行的下一步行动；
- 决议中保留反方意见，降低“AI 替人拍板”的风险；
- 支持 10 分钟无 Key 复现，降低评审使用成本。

对应代码和页面：

```text

src/components/AgoraApp.tsx
README.md
```

### 3. 方法创新性与意图控制（20%）

对应设计：

- 五个 Agent 不是同质化聊天角色，而是有不同原则和职责边界；
- 事实、假设、风险、提案分为不同证据类型；
- 反方质询关系形成冲突图谱；
- 共识记录官必须保留异议；
- 应用层约束事件顺序，不允许 UI 随意拼装模型结果；
- Mock/Live Provider 边界使模型可替换。

对应文件：

```text

src/domain/types.ts
src/application/deliberation-service.ts
src/infrastructure/provider.ts
```
