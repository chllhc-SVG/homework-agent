# 议场 AGORA

> 让不同意见先充分发生，再把决策变成可解释、可回放的行动。

议场 AGORA 是一个面向校园项目、产品评审和团队协作的多智能体决策沙盘。它把一个模糊议题拆成五个互补视角：事实侦察、方案架构、反方质询、影响评估、共识记录；系统记录每条消息、证据、质询关系和决议，形成可回放的决策链路。

## 参赛定位

- 推荐方向：1「多 Agent 协同工作流看板」+ 7「数字孪生与轻量仿真」
- 真实问题：校园团队在产品/大创决策中容易被单一声音主导，异议无法沉淀，复盘缺少证据链。
- 产品闭环：创建议题 → 召集角色 → 多方陈述 → 交叉质询 → 冲突图谱 → 决议书 → 演进回放。
- 可复现设计：默认使用确定性 Mock Provider；无 API Key 也能完整演示，真实 OpenAI 兼容 Provider 可替换接入。

## 10 分钟复现

环境要求：Node.js 20.9+。

```bash
npm install
npm run dev
```

打开 <http://localhost:3000>，点击「召集议场」，再点击「继续交叉质询」或「生成决议草案」。

验证完整工程链路：

```bash
npm run typecheck
npm test
npm run build
```

## 可选的真实模型配置

复制 `.env.example` 为 `.env.local`。支持 OpenAI 兼容 API。推荐先保持空值，评审时使用 Mock 模式验证确定性；若配置真实模型，请勿把 `.env.local` 提交到仓库。

```env
AGORA_LLM_BASE_URL=https://api.deepseek.com/v1
AGORA_LLM_API_KEY=your-key
AGORA_LLM_MODEL=deepseek-chat
AGORA_ENGINE=auto
```

## 架构

```text
src/domain        领域类型、角色阵容、决议算法（纯函数）
src/components    议事厅、冲突图谱、决议书、回放 UI
src/app/api       SSE 流式编排入口
prompts/          AI 协同 Prompt 快照
01-*.md           演进阶段记录
```

核心原则：UI 不直接依赖模型；模型只产生结构化事件；领域层负责约束事件形状；回放使用同一事件序列渲染。因此 Provider 可以替换，决议链路仍可检查。

## 证据与原创性声明

本项目为本次竞赛从零设计的原创作品。作品没有复制既有开源项目的业务代码或视觉页面；依赖包仅用于通用基础能力，并在 `package.json` 中公开列出。竞赛提交前请将本地真实的 Cursor/AI IDE 对话导出文件、截图或录屏放入 `prompts/`，并把对应 Git commit 与 Prompt 编号关联。

## 演示录屏脚本（5—8 分钟）

1. 0:00–0:45：说明校园团队决策痛点与本产品价值。
2. 0:45–2:00：输入议题和背景，展示五个角色的职责约束。
3. 2:00–3:40：启动交叉质询，展示状态、证据置信度和主持人插入约束。
4. 3:40–4:40：打开冲突图谱，解释“张力不是评分，而是验证优先级”。
5. 4:40–5:50：打开决议书，展示行动项、异议记录和可导出结果。
6. 5:50–7:30：打开演进回放，展示事件日志；现场在 Cursor 中重放一条核心 Prompt，并展示从类型检查失败到修复的真实过程。
