# Prompt 02 · 交互闭环与信息层级

## 我的 Prompt

请将议场设计为四个连续状态：议题简报、实时议事厅、冲突图谱、决议书/演进回放。重点展示 Agent 当前状态、证据置信度、质询关系和异议；不要使用通用聊天软件样式；深色编辑部/档案馆气质，琥珀色作为行动信号。

## AI 应答摘要

采用议事厅主工作区、阵容侧栏、张力卡片和可回放导航；用深色墨色、纸张色、琥珀色建立视觉系统；决议书切换为纸张色，形成“从讨论到可交付文件”的对比。

## 人类验收标准

- 评委 10 秒内看懂产品解决什么问题
- 无 API Key 可以启动并看到状态变化
- 决议页同时出现建议、行动项、异议
- 不把冲突强度解释为观点正确性
