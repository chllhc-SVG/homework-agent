## 我的 Prompt

请把竞赛评分标准拆解成一个原创的高校大创/创新创业项目协同工作流看板。核心痛点不是普通聊天，而是跨专业学生团队的需求漂移、风险晚暴露和会后无人负责。请设计五个有严格边界的 Agent：需求洞察员负责用户与证据，工作流架构师负责阶段和交付物，风险质询员负责失败模式，公平与合规官负责隐私/撤回/责任边界，项目统筹官负责负责人、截止时间、验收指标和异议。要求无 API Key 也能 10 分钟复现；将需求卡、工作流卡、风险卡、合规卡、决议卡和事件回放统一进一个产品；先输出领域模型、数据流和模块边界，不要先写 UI。

## AI 应答摘要

确定产品为“议场 AGORA”，将评分点映射为：多 Agent 角色对应创新性；证据与异议对应实用价值；事件序列与 Mock Provider 对应可复现性；严格 TypeScript 领域层对应工程质量。

## 我的人类判断

保留“建议而非自动执行”和“必须保留异议”两个产品原则，避免把多 Agent 做成单纯聊天窗口。
