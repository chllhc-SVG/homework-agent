# 原始 AI 对话导出

本目录用于保存从 Cursor（或其他 AI IDE）实际导出的原始对话文件。官网要求：

> 使用 AI 工具需要导出和 AI 的对话历史，如果 AI 工具不支持导出，可以截图或者录屏。须包含至少 3 个核心功能迭代时与 AI 交互的完整 Prompt 链（包含 Prompt 提问、AI 的修改建议、以及引导 AI 修复 Bug 的过程）。

## 建议文件

```text
prompts/raw/
├─ 01-问题分析-原始导出.html
├─ 01-问题分析-脱敏版.md
├─ 02-方案实施-原始导出.html
├─ 02-方案实施-脱敏版.md
├─ 03-验收测试-原始导出.html
├─ 03-验收测试-脱敏版.md
├─ 04-浏览器验收-原始导出.html
└─ 04-浏览器验收-脱敏版.md
```

## 归档规则

1. 原始导出保持原样，不做删改；
2. 如含 API Key、邮箱、本机用户名等，另存一份脱敏版用于提交；
3. 每份文件头部注明：对话时间、AI 工具、对应截图目录、对应 Git 提交；
4. 原始导出与截图、录屏、Git 提交同时存在，才能构成完整证据链。

## 真实性约束

不得人工编写“看起来像对话”的内容冒充导出文件；不得把本 README 或任何模板当作 AI 原始回复。若 AI 工具不支持导出，请以截图或录屏代替，并在 `prompts/evidence-manifest.md` 中登记。
