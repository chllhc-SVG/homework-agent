## 官网要求的完整链条

比赛要求的完整 Prompt 链应当能按下面顺序核验：

```text
人类提出问题
→ Cursor 分析
→ 人类确认方案
→ Cursor 修改代码
→ 人类发现/提出验收标准
→ Cursor 补充测试或修复
→ typecheck/test/build 通过
→ 对应 Git commit
```

当前三组截图已经能证明问题分析、方案实施和验收测试三个阶段，但截图材料本身仍建议补齐：

1. 每轮的代码 Diff 或 Cursor 文件修改列表；
2. 每轮的明确终端验证截图；
3. 每轮对应的 Git commit 页面或 `git show --stat` 截图；
4. 第 03 轮的校园节能、课程反馈、校园就业浏览器验收截图；
5. Cursor 原始完整对话导出文件；
6. 至少一段包含输入、修改、验证的连续录屏。
